# 업무 요청 분류 도우미

업무 요청을 입력하면 **업무유형, 긴급도, 담당부서**를 추천하고, 결과를 저장해 대시보드로 보여 주는 앱입니다.

> 현재는 **키워드 규칙**으로 추천합니다. 요청 내용은 이 PC 밖으로 전송되지 않습니다.
> 외부 AI 사용 여부는 아직 결정 전입니다. (STATUS.md Q-5)

---

## 1. 처음 한 번만 하는 준비

VS Code에서 이 폴더(`D:\AI\pbl`)를 연 뒤, 메뉴 **터미널 → 새 터미널**을 엽니다. 아래 명령을 한 줄씩 붙여 넣고 Enter를 누르세요.

1. 가상환경 만들기 (이 프로젝트 전용 Python 공간)
   ```
   python -m venv .venv
   ```
2. 필요한 프로그램 설치 (1~2분 걸립니다)
   ```
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

> 가상환경을 "활성화"하지 않아도 됩니다. 모든 명령을 `.\.venv\Scripts\python.exe`로 실행합니다.

## 2. 앱 실행하기

```
.\.venv\Scripts\python.exe -m streamlit run app/main.py
```

- 잠시 후 브라우저에 앱이 열립니다. 열리지 않으면 터미널에 표시된 주소(`http://localhost:8501`)를 브라우저 주소창에 붙여 넣으세요.
- 앱은 **이 PC에서만** 열립니다. 다른 사람의 PC에서는 접속할 수 없습니다.
- 앱을 끄려면 터미널을 클릭하고 **Ctrl + C**를 누릅니다.

## 3. 사용 방법

| 메뉴 | 하는 일 |
|---|---|
| 요청 입력 | 제목과 내용을 입력하고 **AI 추천 받기**를 누릅니다. 추천이 맞지 않으면 드롭다운에서 바꾼 뒤 **저장**합니다. |
| 요청 목록 | 저장된 요청을 표로 봅니다. 업무유형, 긴급도, 담당부서로 거를 수 있습니다. |
| 대시보드 | 전체 건수와 업무유형별, 긴급도별, 담당부서별 차트를 봅니다. 기간(오늘 / 이번 주 / 전체)을 고를 수 있습니다. |

## 4. 저장 위치

- 저장한 요청은 `data\requests.db` 파일 하나에 들어 있습니다. 앱을 껐다 켜도 남아 있습니다.
- 이 파일은 GitHub에 올라가지 않습니다.
- **백업**하려면 앱을 끈 상태에서 이 파일을 복사해 두세요.

## 5. 분류 목록 바꾸기

업무유형, 긴급도, 담당부서와 각 키워드는 `app\config.py` 한 파일에 모여 있습니다. 지금 들어 있는 값은 **임시값**입니다. 실제 회사 기준이 정해지면 이 파일만 고치면 됩니다.

## 6. 테스트 실행 (개발용)

```
.\.venv\Scripts\python.exe -m pytest
```

마지막 줄에 `passed`만 나오고 `failed`가 없으면 정상입니다.

## 7. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| `python`을 찾을 수 없다고 나옴 | Python이 설치되어 있는지 확인합니다: `python --version` |
| `No module named streamlit` | 1번 준비의 2단계(설치)를 다시 실행합니다. |
| 저장할 때 "저장하지 못했습니다"가 나옴 | `data\requests.db` 파일을 다른 프로그램에서 열어 두었는지 확인합니다. |
| 주소가 이미 사용 중이라고 나옴 | 앱이 이미 켜져 있을 수 있습니다. 다른 터미널을 확인하거나 Ctrl + C로 끈 뒤 다시 실행합니다. |
